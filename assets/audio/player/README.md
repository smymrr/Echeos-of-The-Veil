# Medieval Top-Down Pixel Art Asset Pack

Kumpulan aset piksel 16x16 / 32x32 lengkap untuk game RPG / Open World Abad Pertengahan bertema top-down.

## Isi Paket Aset:

### 1. Environment & Tilesets (Lingkungan & Peta)
- **Terrains**: Rumput, Tanah, Jalan Setapak (Dirt Road), Jalan Batu (Cobblestone), Air, Tepian Pantai, Rawa, Sungai.
- **Vegetasi**: Pohon Ek, Pohon Pinus, Semak-semak, Bunga Liar, Jamur, Batang Pohon Tumbang.
- **Struktur**: Rumah Kayu, Pondok Jerami, Kedai (Tavern), Istana/Kastil Batu, Menara Pengawas, Pagar Kayu, Tembok Batu, Gerbang Kastil.
- **Objek Luar**: Sumur Air, Kereta Kuda, Lampu Jalan, Api Unggun, Tenda Pasar, Signpost (Papan Petunjuk), Peti Kayu, Tong.

### 2. Characters & Spritesets (Karakter)
- **Hero / Player**: Kesatria (Knight), Penyihir (Wizard), Pemanah (Archer), Petualang (Adventurer).
- **NPCs**: Penduduk Desa, Pedagang, Pandai Besi, Raja, Pengawal.
- **Monsters / Enemies**: Slime, Serigala (Wolf), Babi Hutan (Boar), Bandit, Goblin, Skeleton.
- **Animasi (4-Arah)**: Idle, Walk, Attack, Hurt, Death.

### 3. Items & UI Elements (Barang & UI)
- **Equipment**: Pedang Besi, Perisai Kayu/Besi, Kapak, Busur & Panah, Tongkat Sihir.
- **Consumables**: Ramuan Merah (HP), Ramuan Biru (MP), Daging, Apel, Roti.
- **Loot**: Koin Emas, Kunci Emas/Besi, Peti Harta Karun (Tutup/Buka), Kantong Koin.
- **UI Elements**: Health Bar, Mana Bar, Window Panel, Frame Inventoris, Icon Skill.
